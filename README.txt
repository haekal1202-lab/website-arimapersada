LPKS ARIMA PERSADA — FULL REDESIGN
==================================

Isi proyek:
- index.html: halaman utama
- program.html: detail program pelatihan
- kebijakan-privasi.html: kebijakan privasi
- syarat-ketentuan.html: syarat & ketentuan
- css/style.css: desain visual terpadu dan responsif
- js/script.js: reveal animation, navigasi mobile, dan FAQ accordion
- assets/: logo, foto kegiatan, serta ilustrasi program

Arah desain:
- Black ink + warm gold, dengan tipografi editorial modern.
- Konsistensi komponen pada seluruh halaman.
- Kartu program berilustrasi, galeri dan testimoni yang lebih rapi.
- FAQ dua kolom di desktop dan satu kolom di mobile.
- Menu mobile dan interaksi FAQ dengan dukungan keyboard.

Cara melihat:
1. Ekstrak ZIP.
2. Buka folder website-arimapersada-main.
3. Buka index.html untuk pratinjau lokal, atau jalankan folder melalui static web server.

Catatan:
- Isi informasi, nama program, jawaban FAQ, tautan, serta hierarki halaman utama dipertahankan.
- Desain telah diperiksa secara statis: semua referensi aset lokal ditemukan, JavaScript lolos pemeriksaan sintaks, dan stylesheet tidak memuat error parser.
- Pengujian visual lintas browser/perangkat penuh belum dapat diselesaikan di lingkungan ini. Lakukan pemeriksaan akhir sebelum mengganti deployment online.

Update gambar program:
- Empat gambar kartu Program Pelatihan telah diganti dengan ilustrasi baru resolusi tinggi.
- File JPEG dioptimalkan dengan kualitas tinggi dan progressive encoding.
- Crop masing-masing kartu serta overlay diperkirakan ulang agar foto lebih terang dan tetap terbaca.
